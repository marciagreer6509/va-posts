Index API Setup

Do this on ONE backup Gmail. No credit card needed.

  1. Log in to the backup Gmail, then open:
    https://console.cloud.google.com/
    If asked, tick "I agree" and continue.
  2. At the top left, click the project box > New Project.
    Name: index-2. Click Create.
    Check that the top bar now says index-2.
  3. Open this link and click Enable:
    https://console.cloud.google.com/apis/library/indexing.googleapis.com
    If it says "API Enabled" or shows "Manage", it's already on.
  4. Open this link:
    https://console.cloud.google.com/iam-admin/serviceaccounts
    Click Create Service Account. Name: index-2. Click Done.
    Skip anything optional. Do not add roles.
  5. In the list, click the new account (index-2@...).
    Open the Keys tab > Add key > Create new key > JSON > Create.
    A file downloads. Do NOT open or edit it.
  6. Upload that file to Google Drive.
    Rename it to the backup Gmail's name, for example: john.smith.json
  7. Right-click the file > Share.
    Under General access, choose Anyone with the link (Viewer).
    Click Copy link, then Done.
  8. Done. You need two things: the Drive link and the backup Gmail address.

Keep the link private. Don't delete the file until you're told to. If a step shows an error or looks different, take a screenshot.
