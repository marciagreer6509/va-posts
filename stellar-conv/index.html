Upload steps

  1. Google Ads → Tools → Data Manager → Upload (or Goals → Conversions → Uploads).
  2. Upload the file above.
  3. Map the first column to Gbraid — NOT "Google Click ID / gclid". This is an iPhone click, so the id is a gbraid; mapping it as a gclid is what failed before.
  4. Map the rest one-to-one (Conversion Name, Time, Value, Currency, Order ID).
  5. Submit. STELLAR already counts Every, so the gbraid is accepted. The time carries -04:00 (ET), so no timezone step is needed.

Note: the API already got this same row accepted — the hold-up has been Google attributing the gbraid, not the upload. If it uploads clean but doesn't show within a day, that's the attribution lag, not the file.
