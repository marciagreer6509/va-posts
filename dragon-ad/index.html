🐉 Dragon ads: launch sheet

Launch these 3 ads. Everything you need is on this page, nothing else to read.

Step 1 · Create the campaign (Ads Manager on a computer)

  1. + Create → objective Traffic. Name it Dragon US. Advantage campaign budget OFF.
  2. Ad set: Website · goal Maximise link clicks · $20/day · start tomorrow 00:00.
  3. Audience: United States, age 35–65+, all genders, no interests.
  4. Placements → Manual: Facebook Feed, Instagram Feed, FB Reels, IG Reels, Stories. Untick Audience Network + Messenger.

Step 2 · These are the same on all 3 ads

Website URL

URL parameters

The Website URL box is your Blitz DragonFlame link (c=11565, $45 per sale). Paste URL parameters into the "URL parameters" box under Tracking. Blitz then shows which ad sold.

Step 3 · Make 3 ads in the ad set

For each ad, upload the 9:16 video and the 1:1 video (Facebook asks for both). Then copy the name, text and headline. Turn Advantage+ creative OFF. Press Preview, then Publish.

Step 4 · After launch

Days 1–3: don't touch anything. Check once a day. Any edit restarts Facebook's learning.
Turn an ad OFF when, after ~1,000 views:
  • Link CTR is under 0.8%, or
  • Cost per link click is over $1.00, or
  • It has spent $68 with 0 sales in Blitz.
Winner = cost per sale under $45 for 2 days. Raise the budget +20% every 2 days, no faster. Then swap a spare (below) in for each ad you turned off.
Spare ads: only use these to replace an ad you turned off
