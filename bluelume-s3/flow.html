How one BlueLume spam result works — start to finish

Search query → Google result → the page on someone else's S3 bucket → the split → where a human really ends up.

1

🔍 Google search: "bluelume glasses review"

The result shows up as a video (thumbnail + title), not a normal blue link. It sits in the Videos block because the page carries VideoObject schema + a real .mp4 — so Google treats it as a video and gives it a big thumbnail.

▼ user clicks
2

📄 The page — on a stranger's Amazon S3 bucket

bucket-irwinwebsite.s3.ap-southeast-2.amazonaws.com/…/ktarxd93.html

Keyword text + fake "reviews/ingredients/official" menu. It looks broken (no styling) because every /_next/ CSS & JS file returns 403. It isn't meant to be read by a human — its only two jobs are to rank and to load one script: lumoraavena.shop/js/bluelumeglassesvisionlens.js

▼ that script runs
3

🔀 The split — the script checks who you are

if (!userAgent.includes("Googlebot")) → redirect. One line decides everything:

✅ If you're Googlebot

Nothing happens. Google quietly reads the text + video and keeps the page in the index. It never sees a redirect, so it never knows it's a trap.

➡️ If you're a human

Instantly bounced off the S3 page to:

cybomint.org / lumoraavena.shop /recommend/<slug>

▼ human only, keeps moving
4

↪️ /recommend/ page → meta-refresh to the affiliate tracker

global-dailyupdates.com/6DXMWFN/K7ZTJQX/

6DXMWFN = their affiliate ID (same ID shows on their other products) · K7ZTJQX = this offer. This is the link that pays them.

▼
5

🛒 The real product checkout

The only page a human actually sees and reads. Everything before it existed just to get the click here and tag it to affiliate 6DXMWFN.

The one-line summary

🟢
Google sees a tidy video review page and ranks it.
🔴
You never see that page — you're thrown straight to an affiliate offer. Same URL, two completely different experiences. That's the trick (it's called cloaking).
