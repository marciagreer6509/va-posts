Bansal Skin Clinic · near Fauji Chowk, Bathinda. Open the profile at business.google.com (or search the name on Google while logged in) → Edit profile. Each section below says where to click, what to type, and shows the finished result.

0The order to do it in

Google re-checks a profile when big fields change. Doing them in this order keeps it live and verified:

  1. Security — clean the owners list (section 1).
  2. Safe fields — phone, hours, description, services, booking link, Facebook link, opening date (sections 4–9).
  3. Category (section 3).
  4. Map pin (section 10). Keep someone at the clinic ready in case Google asks for a short verification video.
  5. Name — no change. Keep “Bansal Skin Clinic” (section 2).
  6. Photos + one Update + reply to reviews (sections 11–13), every week from now on.
After every save, the edit shows as “Under review” for a few minutes to a few days. Wait for it to clear before the next big one (category → pin → name).
