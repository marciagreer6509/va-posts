Trend Checker on another PC: setup

  1. On the other PC press the Windows key, type PowerShell, press Enter.
  2. Paste the one line you got in the chat (right-click pastes), press Enter.
  3. Wait 3–5 minutes. It installs Git and Claude Code, downloads the project to Desktop\trend-checker and makes a Desktop shortcut Trend Checker - Claude.
  4. First time only: a browser opens. Sign in to your Claude account.
  5. Next time: double-click Trend Checker - Claude on the Desktop.

If Windows asks "Do you want to allow this app to make changes?", click Yes (that is the Git installer). If anything goes red, paste the same line again.
