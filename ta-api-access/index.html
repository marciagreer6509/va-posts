1Buy the domain YOU

  1. Buy trusted-access.org and add it to Cloudflare.
  2. With the company account, open Search Console → Add property → Domain → trusted-access.org.
  3. Send me the TXT code it shows. I add it, you click Verify.

2Website + missing features ME

  1. I build the homepage, privacy, terms and contact pages. I need: company legal name, address and support email.
  2. I add what Google checks before Standard: create conversion tracking, account callouts, remove campaigns/ads/keywords, bidding strategy report.
  3. I make a test login for Google's reviewer.

3Google Cloud project YOU

  1. Open console.cloud.google.com with the company account.
  2. Best: move the current project into the company: open the current project → IAM & Admin → Settings → Migrate. It keeps Basic access and all client connections.
    If Migrate isn't allowed: New project "Trusted Access" → APIs & Services → Library → "Google Ads API" → Enable. Clients then reconnect once.
  3. Billing: link a paid card. Google refuses projects on the free trial.
  4. IAM → Grant access: add 2 more people as Owner, so one lockout can't kill it.

4Consent screen YOU

APIs & Services → OAuth consent screen, then these tabs:

  1. Branding: name Trusted Access, logo (square PNG 120×120 px), homepage https://trusted-access.org, privacy https://trusted-access.org/privacy, terms https://trusted-access.org/terms, authorized domain trusted-access.org → Save.
  2. Audience: External + Publish app (In production).
  3. Data Access → Add or remove scopes → paste https://www.googleapis.com/auth/adwords → Update → Save.
  4. Clients (only for a new project): Create client → Web application → redirect https://trusted-access.org/connect/cb → send me the JSON.

5Verify, then Basic YOU + ME

  1. Branding → Verify branding (minutes) → Publish branding. Send me any error it shows.
  2. APIs & Services → Google Ads API → Overview → Upgrade access level → Apply for access. New project: Explorer first, then Basic. Usually minutes.
  3. I record the demo video. You upload it to YouTube as Unlisted.
  4. Verification Center → Submit for verification: video link + the text below. This removes the red warning clients see.
Text to paste: why we need the permission
Trusted Access is a campaign management tool for advertising agencies and their clients. The client signs in with Google and grants the Google Ads permission so the agency can see the client's Google Ads accounts and reports, and create, edit, pause and remove campaigns, ad groups, keywords, ads, budgets and targeting. The Google Ads API offers only this one permission; there is no narrower one. Data is used only to show users their own accounts and to make the changes they ask for. It is never sold, used for advertising or shared.

6Apply for Standard YOU, after I say go

  1. Google Ads API → Overview → Upgrade access level → Start application.
  2. Choose: external users / full-service · use = Ad creation / management.
  3. Paste the text below. Give the reviewer login from step 2, never your own.
  4. Google emails the company account with questions. Answer the same day.
Text to paste: what the tool does
Trusted Access (https://trusted-access.org) is a web-based Google Ads management tool run by [COMPANY NAME] for our agency team and our advertiser clients. Each client connects their own Google Ads account through Google sign-in. Our team uses it to create and launch Search and Display campaigns (budgets, Target CPA / Target ROAS / Maximize Conversions bidding, location and language targeting, ad groups, keywords with match types, negative keywords, ads, placement exclusions), to pause, enable, edit and remove them, and to report on accounts, campaigns, ad groups, ads, keywords, search terms and bidding strategies (clicks, impressions, cost, conversions). Every change can first be checked with validate-only. Users: about [N] staff managing about [N] client accounts.
