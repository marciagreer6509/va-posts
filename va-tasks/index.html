3 · Find old health domains (expireddomains.net + Wayback Machine)

Every daySend up to 10 good names a dayDo not buy anything

We are looking for old health, pharmacy, vitamin or natural-food website names that were deleted and are free to register again.

Part A · Log in (first time)

  1. Open https://www.expireddomains.net/login/.
  2. Username and password: in the accounts map, row expireddomains.net.
  3. The site will ask for a code sent by email. That email goes to Bob. Message Bob: "expireddomains code please" and type the code he sends you.

Part B · Find names

  1. Click one keyword below (the links only work after you log in). Each one opens a list sorted by the number of sites linking to the name.
  2. Look at these columns for each row:
    • ABY = first year the site was saved in the archive → must be 2016 or earlier
    • ACR = how many times it was saved → must be 10 or more
    • DP = sites linking to it → 5 or more
    • Status → must say available
  3. Skip names with: viagra, cialis, casino, bet, loan, cbd, porn, sex, replica, or random letters.
  4. Copy the names that pass into your list. Do every keyword once a week. New deleted names appear every day.

Part C · Check each name's history (Wayback Machine)

  1. Open https://web.archive.org/web/*/NAME, with the domain in place of NAME. Example: https://web.archive.org/web/*/betterhealthways.com.
  2. Click the calendar view. For each year with a dot, click one saved day and look at the page.
  3. Write down what it was each year (example: "2012–2016 vitamin shop in Ohio").
  4. GOOD = a real health/pharmacy/vitamin/natural-food shop or blog in every year.
  5. REJECT if any year shows pills (viagra/cialis), casino, porn, loans, fake brand shops (Nike, Ray-Ban…), a foreign-language shop selling something else, or a "this domain is for sale" page in more than half of the years.
