What gets built

The EXE

FileTrendDesk-v1.0-win64.zip → unzip → Trend Desk.exe (no installer, Windows 10/11).
Sign-inThe same logins and seats as the web app. The EXE gives the server a proper computer ID, so a licence is tied to the PC, not the browser.
UpdatesThe app screens load from the Trend Desk server, so fixes arrive without a new EXE. Only engine changes need a new download.
PicturesVeo Flow Multi's proven engine: one separate, saved Google session per account, a hidden Flow window per account for Google's security check, images through Flow's own API.
FilesThe CSVs save straight to a folder you pick (Documents\Trend Desk\<date>) instead of Downloads.
Built onElectron (like Veo Flow Multi). First run tested on the Beast before it goes to the client.
